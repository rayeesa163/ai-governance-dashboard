
# AI Governance & Analytics Dashboard

A responsive front-end dashboard prototype designed to provide visibility into organizational AI adoption, spending, budget utilization, tool approvals, and governance risks.

The dashboard presents business and operational metrics in a decision-oriented interface to help stakeholders understand AI usage, monitor spending, and identify areas requiring governance review.

## Features

- **Executive KPI Dashboard:** Displays total AI spend, monthly budget, budget utilization, active users, unapproved AI tools, and policy violations.
- **AI Spend Analysis:** Visualizes monthly spending trends and budget comparisons.
- **Vendor-wise Usage:** Displays AI tool adoption, user counts, spending, and percentage contribution.
- **Department Budget Monitoring:** Compares department-level spending against allocated budgets.
- **Governance Alerts:** Highlights critical, warning, and informational alerts.
- **AI Tool Approval Tracking:** Summarizes approved, pending, and unapproved AI tools.
- **Product Insights:** Highlights spending concentration, potential budget risks, and recommended review actions.
- **Responsive UI:** Adapts to desktop, tablet, and mobile screen sizes.
- **Interactive Elements:** Includes navigation selection, date-range selection, dynamic table rendering, and notification messages.

## Getting Started

### Prerequisites

A modern web browser is required.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rayeesa163/ai-governance-dashboard.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ai-governance-dashboard
   ```

3. Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## Current Limitations

- Uses hard-coded demonstration data.
- Does not have live vendor API or finance-system integrations.
- Filters and approval controls are currently UI demonstrations.
- Does not include authentication, backend services, or persistent storage.
- Forecast values are illustrative rather than model-generated predictions.
